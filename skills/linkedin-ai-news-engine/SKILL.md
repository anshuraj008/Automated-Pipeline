# Tech & Full Stack Content Engine

Select or create one high-impact technical post covering one of three core pillars:

1. **Full Stack & Web Development**: Practical architectural insights, React/Next.js/Node.js best practices, web performance, API design, or modern dev tools.
2. **DSA & System Design**: Key algorithm patterns (Two Pointers, Sliding Window, DP, Graphs), data structure trade-offs, Big-O complexity, or system design principles.
3. **AI & Tech Innovation**: Verifiable AI developments, named model launches, developer tooling, or research with practical consequences.

## Content Pillars & Topic Selection

Use `ai_news_data.json` fetched by `fetch_ai_news_rss.py` as a primary source for tech news, or select a high-value engineering topic in Full Stack Dev / DSA. Rotate topics regularly across posts:

- **Mon/Wed**: Full Stack & Web Development (Architecture, React/Next.js, Node.js, Databases, Web Performance)
- **Tue/Thu**: Data Structures & Algorithms (DSA patterns, time/space complexity, problem-solving techniques)
- **Fri/Sat**: AI News & Developer Tools (Latest AI models, APIs, developer ecosystem updates)

## Caption Guidelines

Write exactly one caption suitable for both LinkedIn and X:

- Maximum 280 characters, including spaces.
- Name the specific tech topic, framework, algorithm pattern, or news story.
- State the key technical insight, trade-off, or breaking change clearly.
- No URLs in caption body, no spammy hashtags, no clickbait or fake claims.
- Direct, engineering-first tone with immediate practical value.

## Visual Prompt Guidelines

Return a detailed Antigravity prompt for generating a 1080x1080 graphic:

- **Full Stack / Web Dev**: System architecture flowcharts, API data flows, tech stack comparison tables, or clean code architecture diagrams.
- **DSA / Algorithms**: Visual algorithm trace (e.g. array pointers, tree traversal, time complexity comparison graph).
- **AI / Tech News**: Editorial visual metaphor, system diagram, key metric, or launch summary.
- **Visual Style**: 1080x1080 square composition, dark charcoal (#121212) background, vibrant accent color (cyan, emerald, or violet), high-contrast modern typography, minimal 2-4 key labels, mobile-first legibility.

The final image is generated by Antigravity only.
