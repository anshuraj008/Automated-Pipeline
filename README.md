# AI News Scheduler

This repository does one job: fetch recent AI news, write one concise update,
prepare a high-quality Antigravity image prompt, and schedule one post through
Buffer. It contains no personal-project, build-in-public, Reddit, or
performance-content workflow.

## What runs

```text
Fetch RSS feeds
    -> filter/dedupe the last 7 days
    -> Antigravity researches one story and writes <=280 characters
    -> Antigravity generates one 1080x1080 image from image_prompt.txt
    -> user supplies a public image URL
    -> build exactly one schedule entry
    -> Buffer dry run
    -> Buffer live schedule
```

The default target is the same single post on LinkedIn and X. The caption is
limited to 280 characters so both channels can receive it unchanged. Use
`--target linkedin` if X is not configured.

## Setup

Python 3.10+ is required. Put these values in `.env`:

```text
BUFFER_API_KEY=...
BUFFER_ORG_ID=...
BUFFER_LINKEDIN_CHANNEL_ID=...
BUFFER_X_CHANNEL_ID=...
```

## Run

Antigravity first fetches the feeds, researches the story, and writes:

```bash
python3 fetch_ai_news_rss.py
```

This creates:

- `ai_news_data.json`: current RSS candidates
- `linkedin_post.json`: one caption and source
- `image_prompt.txt`: prompt for Antigravity

After Antigravity generates and publicly hosts the image:

```bash
python3 run_pipeline.py --image-url "https://public.example/image.png" --live
```

The command always previews first. Without `--live`, nothing is scheduled.
The Python runner does not call an LLM. It validates Antigravity's files, builds
the schedule, previews Buffer, and optionally schedules live.

## Files

- `fetch_ai_news_rss.py`: source collection, deduplication, and seven-day filter
- `validate_antigravity_output.py`: validates Antigravity's caption and prompt
- `daily-linkedin-posts/SKILL.md`: Antigravity orchestration instructions
- `skills/linkedin-ai-news-engine/SKILL.md`: research and writing rules
- `build_schedule.py`: enforces exactly one scheduled post
- `schedule_via_buffer.py`: dry-run and live Buffer scheduling
- `buffer_client.py`, `env_utils.py`: Buffer API and environment helpers

Images are intentionally not generated by Python or HTML templates. The
visual step belongs to Antigravity so each image can be reviewed for clarity,
accuracy, and mobile readability before scheduling.
